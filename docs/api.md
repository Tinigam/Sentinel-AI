# V1 API Specification

Base URL: `/api/v1`  
Format: JSON, UTF-8  
Time: ISO 8601 UTC, for example `2026-08-04T08:30:00Z`

All list endpoints use `page` (default `1`, minimum `1`) and `page_size` (default `20`, maximum `100`). Successful responses use `200` unless noted. Error responses use the envelope below.

```json
{
  "error": {
    "code": "validation_error",
    "message": "date_from must be before date_to",
    "details": [{"field": "date_from", "message": "invalid range"}],
    "request_id": "uuid"
  }
}
```

## Endpoints

### `GET /health`

Returns service and dependency readiness. It must not expose secrets.

```json
{"status":"ok","database":"ok","version":"0.1.0"}
```

### `GET /topics`

Returns active games. `slug` is the value used by query parameters and RAG filters.

### `GET /news`

Query parameters: `topic`, `sentiment`, `date_from`, `date_to`, `source`, `search`, `page`, `page_size`, `sort`.

Allowed `sort`: `published_at_desc` (default), `published_at_asc`, `relevance_desc`.

```json
{
  "items": [{
    "id": "uuid",
    "title": "...",
    "summary": "...",
    "source": {"name": "GameLook", "domain": "gamelook.com.cn"},
    "published_at": "2026-08-04T08:30:00Z",
    "url": "https://example.com/article",
    "topics": [{"slug": "wuthering-waves", "display_name": "鸣潮"}],
    "sentiments": [{"topic_slug": "wuthering-waves", "label": "negative", "confidence": 0.82}]
  }],
  "pagination": {"page": 1, "page_size": 20, "total": 143}
}
```

### `GET /news/{article_id}`

Returns a single article, all linked topics, game-level sentiments, processing state, and original URL. `404` is returned when unavailable.

### `GET /dashboard/summary`

Optional filters: `topic`, `date_from`, `date_to`.

Returns total article count, today count, topic ranking, and overall sentiment distribution. Counts must be calculated from indexed articles only.

### `GET /dashboard/trends`

Optional filters: `topic`, `date_from`, `date_to`, `granularity` (`day` only in V1).

```json
{
  "granularity": "day",
  "series": [{
    "date": "2026-08-04",
    "article_count": 18,
    "positive_count": 5,
    "neutral_count": 9,
    "negative_count": 4
  }]
}
```

### `POST /ask`

Request:

```json
{
  "question": "最近鸣潮为什么负面增加？",
  "topic": "wuthering-waves",
  "date_from": "2026-07-28T00:00:00Z",
  "date_to": "2026-08-04T23:59:59Z",
  "sentiment": "negative"
}
```

`topic` and filter fields are optional; the service parses omitted fields from the question. The API must reject questions longer than 1,000 characters.

Response:

```json
{
  "answer": "近期负面讨论主要集中在…… [article_12]",
  "summary_points": [{
    "claim": "主要讨论集中在……",
    "citation_ids": ["article_12", "article_35"]
  }],
  "sources": [{
    "id": "article_12",
    "title": "Example article",
    "source": "Example News",
    "published_at": "2026-08-02T08:30:00Z",
    "url": "https://example.com/article",
    "snippet": "Relevant supporting passage..."
  }],
  "query": {"topic": "wuthering-waves", "date_from": "2026-07-28T00:00:00Z", "date_to": "2026-08-04T23:59:59Z"},
  "retrieval": {"method": "hybrid_rrf", "candidate_count": 40, "source_count": 5},
  "insufficient_evidence": false,
  "request_id": "uuid"
}
```

Every `citation_id` must exist in `sources`; citations not returned by retrieval must be removed before responding. A low-evidence response must set `insufficient_evidence` to `true` and avoid unsupported claims.

### `POST /ingest`

Development-only endpoint. Require `X-Ingest-Key` in non-development environments. Request accepts optional `source_id` and `mode` (`incremental` or `backfill`); return `202 Accepted` with an ingestion run ID.

## Status Codes

| Code | Meaning |
| --- | --- |
| `200` | Successful request |
| `202` | Ingestion accepted |
| `400` | Invalid filter or malformed request |
| `401` | Missing or invalid ingestion key |
| `404` | Resource not found |
| `422` | Schema validation failure |
| `429` | Rate limit exceeded |
| `500` | Unexpected server failure |
| `503` | Database or LLM dependency unavailable |

OpenAPI generated by FastAPI is available at `/docs` in development only. Production must disable public interactive documentation or protect it with the same access policy as the API.
## Content quality filters

`GET /api/v1/news` accepts optional `content_type`. By default, news, dashboard and RAG endpoints only include articles where `is_intelligence=true` (`official_announcement` and `media_news`).
